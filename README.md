# HearO Admin

HearO 서비스의 관리자 기능을 담당하는 저장소입니다.

사용자 유형별 정보를 조회하고, 서비스 이용 현황과 진료 기록을 관리하기 위한 관리자 도메인 및 Repository 코드를 포함합니다.

## 주요 기능

- 피보호자 목록 조회 및 페이징
- 보호자 목록 조회 및 페이징
- 의료기관 사용자 목록 조회 및 페이징
- 사용자 이름 또는 아이디 검색
- 회원가입 날짜 및 마지막 로그인 시간 조회
- 피보호자별 질병 진료 횟수 집계
- 피보호자의 보호자 수 조회
- 보호자의 피보호자 수 조회
- 의료기관 사용자의 완료 진료 수 조회

## 질병 통계

피보호자의 진료 아카이브를 기준으로 질병별 횟수를 집계합니다.

현재 지원하는 질병 분류는 다음과 같습니다.

- `COLD`
- `UNDEFINED_1` ~ `UNDEFINED_8`
- `OTHER`

분류되지 않은 질병은 `OTHER`로 집계됩니다.

## 사용 기술

- Java
- Spring Boot
- Spring Data JPA
- QueryDSL
- Lombok

## 현재 개발 상태

현재 관리자 도메인, 사용자 조회 DTO 및 QueryDSL 기반 Repository가 구현되어 있습니다.

아카이브 상세 조회, 보호 관계 관리, 관리자 Controller와 Service는 추후 구현할 예정입니다.

목록별 추가 집계 쿼리는 현재 사용자마다 별도로 조회하고 있으며, 이후 사용자 ID를 모아 한 번에 집계하는 방식으로 최적화할 예정입니다.

## 연동

본 저장소의 관리자 코드는 HearO Backend의 사용자, 진료 아카이브, 보호 관계 및 의료기관 도메인을 기반으로 동작합니다.
