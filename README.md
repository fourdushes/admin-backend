# HearO Admin

HearO 서비스의 관리자 기능을 담당하는 백엔드 코드입니다.

## 주요 기능

- 관리자 로그인
- 피보호자·보호자·기관 사용자 목록 조회
- 가입일과 검색어를 이용한 사용자 조회
- 지역과 요청일을 이용한 기관 조회
- 기관별 소속 사용자 조회
- 피보호자별 아카이브 목록 및 상세 조회
- 보호자·피보호자 관계 조회
- 기관 가입 요청 승인 및 거절
- 사용자·기관·아카이브·보호 관계 관리

## 조회 기능

관리자 목록에서는 다음 조건을 이용할 수 있습니다.

- 아이디 또는 이름
- 시작일과 종료일
- 사용자 상태
- 기관 승인 상태
- 기관 지역
- 페이지 번호와 페이지 크기

날짜는 연·월·일을 기준으로 조회합니다.

## 패키지 구조

```text
admin
├── auth          # 관리자 인증
├── config        # 관리자 설정
├── controller    # 관리자 요청 처리
├── domain        # 관리자 도메인
├── dto
│   ├── request   # 요청 DTO
│   └── response  # 응답 DTO
├── repository    # 데이터 조회
└── service       # 관리자 비즈니스 로직
```

## 테스트

관리자 Repository 테스트에서는 다음 기능을 확인합니다.

- 사용자 유형별 목록 조회
- 검색어와 날짜 조건 적용
- 기관 상태 및 지역 조회
- 페이지 처리와 전체 개수 계산
- 기관별 소속 사용자 조회
