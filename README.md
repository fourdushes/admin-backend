# HearO Admin Backend

HearO 서비스 운영을 위한 관리자 기능을 제공합니다.

## 주요 기능

- 사용자 목록 조회 및 검색
- 기관과 소속 사용자 조회
- 기관 가입 요청 관리
- 사용자별 진료 기록 조회
- 보호자·피보호자 연결 관계 조회
- 서비스 운영 데이터 관리

## 보호관계 조회

승인된 보호관계를 관리자가 확인할 수 있습니다.

- 피보호자 또는 보호자 아이디 검색
- 피보호자·보호자 정보 확인
- 주 보호자 여부 확인
- 관계 요청일 및 승인일 확인
- 페이지 단위 목록 조회

## 조회 조건

기능에 따라 다음 조건을 이용할 수 있습니다.

- 검색어
- 조회 기간
- 사용자 및 기관 상태
- 기관 지역
- 페이지 번호와 페이지 크기

## 테스트

목록 조회, 검색 조건, 연관 데이터 조회와 페이지 처리가 정상적으로 동작하는지 확인합니다.
